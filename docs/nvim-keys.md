# Клавиши моего Neovim

Справка для конфига `nvim/init.lua` и `nvim/after/ftplugin/python.lua`.
Leader — **запятая `,`**. Например, `,f` означает нажать запятую, затем `f`.
`Space rn` — пробел, затем `r`, затем `n`; эти LSP-команды используют именно пробел.
`Ctrl-X` — удерживать Ctrl и нажать X; `Shift-Tab` — Tab с Shift.

По умолчанию команды ниже работают в **обычном режиме** (Normal).
Выйти в него: `Esc`; из режима ввода также можно набрать `jk`.
Клавиши внутри Telescope, Oil и меню дополнения действуют только в этих окнах.

## Самое нужное

| Клавиши | Действие |
| --- | --- |
| `i` / `a` | Ввод перед курсором / после курсора |
| `jk` или `Esc` | Выйти из ввода |
| `:w` + Enter | Сохранить файл |
| `:q` + Enter | Закрыть окно; при несохранённых изменениях попросит сохранить |
| `:wq` + Enter | Сохранить и закрыть окно |
| `:q!` + Enter | Закрыть окно, отказавшись от несохранённых изменений |
| `u` / `Ctrl-R` | Отменить / повторить изменение |
| `,f` | Найти файл через Telescope |
| `,g` | Искать текст в проекте через Telescope и ripgrep |
| `,e` | Открыть/закрыть левый файловый проводник netrw |
| `,` затем пробел | Убрать подсветку результатов поиска |
| `gw` | Переключиться на предыдущий буфер и удалить текущий из списка буферов |
| `H` / `L` | Предыдущая / следующая вкладка Neovim |

Включено автосохранение через auto-save.nvim. Явное `:w` всё равно удобно перед
запуском программы. `gw` может отказаться закрыть буфер с несохранёнными изменениями.
Вкладка (tab), окно (split) и открытый файл (buffer) — разные сущности.

## Поиск файлов и текста: Telescope

Открыть: `,f` для файлов, `,g` для текста. Начни печатать запрос.
Поиск идёт от текущего рабочего каталога Neovim (`:pwd`), обычно каталога запуска.

| Клавиши в строке поиска | Действие |
| --- | --- |
| `Ctrl-N` / `Ctrl-P` | Следующий / предыдущий результат |
| Enter | Открыть результат |
| `Ctrl-V` | Открыть в вертикальном разделении окна |
| `Ctrl-X` | Открыть в горизонтальном разделении окна |
| `Ctrl-T` | Открыть в новой вкладке |
| `Ctrl-D` / `Ctrl-U` | Прокрутить предпросмотр вниз / вверх |
| Tab / Shift-Tab | Отметить результат и переместиться по списку |
| `Ctrl-Q` | Отправить результаты в quickfix и открыть список |
| `Ctrl-C` | Закрыть поиск |
| Esc | Из ввода перейти в обычный режим окна поиска |

В обычном режиме Telescope: `j`/`k` перемещают по результатам, `q` или Esc закрывают окно.
Файлы `.pyc`, `.pyo` и каталоги `__pycache__` исключены настройками.

## Проводники

### netrw: `,e`

| Клавиши в проводнике | Действие |
| --- | --- |
| `j` / `k` | Перемещаться по списку |
| Enter | Открыть файл или каталог |
| `-` | Перейти в родительский каталог |
| `o` / `v` | Открыть файл в горизонтальном / вертикальном разделении |
| `t` | Открыть файл в новой вкладке |
| `,e` | Закрыть проводник |

### Oil: `:Oil` + Enter

Oil установлен отдельно. Команда `,e` открывает netrw; Oil открывается через `:Oil`.
В Oil список файлов можно редактировать как текст: переименовать строку, добавить
новую, удалить строку. `:w` применяет изменения файловой системы и при необходимости
показывает подтверждение.

| Клавиши в Oil | Действие |
| --- | --- |
| Enter | Открыть файл/каталог |
| `t` или `Ctrl-T` | Открыть в новой вкладке |
| `Ctrl-S` / `Ctrl-H` | Открыть в вертикальном / горизонтальном разделении |
| `Ctrl-P` | Предпросмотр |
| `-` | Родительский каталог |
| `_` | Рабочий каталог Neovim |
| `g.` | Показать/скрыть скрытые файлы |
| `Ctrl-L` | Обновить список |
| `Ctrl-C` | Закрыть Oil |
| `g?` | Показать справку по клавишам |

## Код: LSP

Эти привязки появляются в буфере при подключении настроенного language server:
Pyright, TypeScript, gopls или rust-analyzer. Go/Rust требуют установки своих серверов.
Состояние можно посмотреть через `:checkhealth vim.lsp`.

| Клавиши | Действие |
| --- | --- |
| `gd` | Перейти к определению |
| `gi` | Перейти к реализации |
| `gr` | Найти места использования |
| `K` | Документация/информация под курсором |
| `Ctrl-K` | Подсказка сигнатуры функции |
| `Space rn` | Переименовать символ |
| `Space ca` | Доступные действия с кодом |
| `Space e` | Показать диагностику под курсором |
| `[d` / `]d` | Предыдущая / следующая диагностика |
| `Space q` | Собрать диагностику в location list |
| `Space f` | Асинхронно форматировать текущий буфер |
| `Ctrl-O` / `Ctrl-I` | Назад / вперёд по истории переходов |

Форматирование работает, если подключённый сервер его поддерживает.
Prettier подключён через none-ls для поддерживаемых им файлов. Pyright сам по себе
не форматирует Python; отдельный Python-форматтер в этом конфиге не настроен.

## Дополнение и сниппеты

Работают **в режиме ввода**. Автоматическое открытие меню дополнения выключено.

| Клавиши | Действие |
| --- | --- |
| `Ctrl-Space` | Вызвать дополнение вручную |
| `Ctrl-N` / `Ctrl-P` | Следующий / предыдущий вариант |
| Enter | Принять выбранный вариант; если выбор не сделан — первый |
| `Ctrl-E` | Закрыть меню дополнения |
| Tab | Раскрыть доступный сниппет LuaSnip или перейти к следующему полю |
| Shift-Tab | Перейти к предыдущему полю сниппета |

Пользовательские сниппеты лежат в `nvim/snippets/`. Tab в текущем конфиге
переопределён для LuaSnip: если раскрывать нечего и активного сниппета нет,
обычную табуляцию эта привязка не вставляет. Для отступов в Normal можно использовать `>>`/`<<`.
Некоторые терминалы передают Ctrl-Space как Ctrl-@; проверить привязку: `:verbose imap <C-Space>`.

## Комментарии

| Клавиши | Действие |
| --- | --- |
| `,cc` | Закомментировать/раскомментировать текущую строку |
| `,cb` | Переключить блочный комментарий |
| Выделить строки через `V`, затем `,c` | Переключить строчные комментарии выделения |
| Выделить через `v`, затем `,b` | Переключить блочный комментарий выделения |
| `,cip` | Переключить строчные комментарии для текущего абзаца |

Возможность блочного комментария зависит от языка файла.

## Скобки и кавычки: mini.surround

| Клавиши | Действие |
| --- | --- |
| `saiw)` | Обернуть слово в круглые скобки: `word` → `(word)` |
| `saiw"` | Обернуть слово в двойные кавычки |
| Выделить текст через `v`, затем `sa)` | Обернуть выделение в круглые скобки |
| `sd)` | Удалить окружающие круглые скобки |
| `sr)"` | Заменить окружающие круглые скобки двойными кавычками |
| `sf)` / `sF)` | Найти окружающую круглую скобку справа / слева |
| `sh)` | Подсветить окружающие круглые скобки |

Для добавления `)` даёт `(text)`, а `(` — `( text )`; аналогично для `]`/`[` и `}`/`{`.

## Запуск текущего файла

`Ctrl-H` работает в Normal и Insert: сохраняет файл и выполняет команду.

| Тип файла | Команда |
| --- | --- |
| Python | `uv run python <текущий файл>` |
| C | `gcc <текущий файл> -o out; ./out` |
| Shell | Выполнить текущий файл напрямую |
| Go | Тоже выполнить файл напрямую — `go run` этой клавишей пока не настроен |

Для shell нужны путь к исполняемому файлу, разрешение на запуск и подходящий shebang.
Команда запуска C использует `;`: после ошибки компиляции может запуститься уже
существующий `out`. Текущие команды запуска не экранируют имена файлов с пробелами.
В Oil `Ctrl-H` имеет другое назначение: горизонтальное разделение окна.

## Python и Markdown

В Python переходы работают в Normal, Visual и после оператора (`d`, `y` и т. п.).

| Клавиши | Действие |
| --- | --- |
| `]]` | Следующая функция/метод, включая вложенные и `async def` |
| `[[` | Предыдущая функция/метод |
| `3]]` | Перейти на три функции вперёд |
| `Ctrl-O` | Вернуться к позиции до перехода |

Для содержимого между строками с тройными обратными кавычками настроен текстовый объект:

| Последовательность | Действие |
| --- | --- |
| <code>vi`</code> | Выделить содержимое блока |
| <code>yi`</code> | Скопировать содержимое блока |
| <code>di`</code> | Удалить содержимое блока |
| <code>ci`</code> | Заменить содержимое блока |

Курсор должен находиться внутри блока; строки с ограждающими кавычками в выделение не входят.
Эта привязка ищет строки с тройными кавычками и заменяет стандартный объект для одиночных backticks.

| Клавиши/команда | Действие |
| --- | --- |

| `w` / `b` | Следующее / предыдущее слово |
| `0` / `^` / `$` | Начало строки / первый непробельный символ / конец строки |
| `gg` / `G` | Начало / конец файла |

| `n` / `N` | Повторить поиск в том же / обратном направлении |
| `v` / `V` / `Ctrl-V` | Выделение символов / строк / прямоугольника |
| `yy` / `dd` / `p` | Скопировать строку / вырезать строку / вставить после курсора |
| `ciw` | Заменить слово под курсором |
| `>>` / `<<` | Увеличить / уменьшить отступ |

| `:lopen`, `:lnext`, `:lprev` | Location list и переходы по нему |

## Плагины и проверка привязок

- `:Lazy` — менеджер плагинов; `:Lazy update` — обновление.
- `:checkhealth` — диагностика редактора и инструментов.
- `:verbose nmap ,f` — показать привязку `,f` и где она задана.
- `:verbose imap <Tab>` — проверить Tab в режиме ввода.
- `:map` — список привязок; `:help <тема>` — встроенная справка.

Клавиши чувствительны к регистру. Используй латинскую раскладку для команд.
