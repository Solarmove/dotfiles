# Neovim craftzdog + Python

Основа: https://github.com/craftzdog/dotfiles, commit
`7c50fa72f64aada314c124cea005fd923e9f5c0f` (6 ноября 2026).
Neovim 0.12.6 установлен в `~/.local/opt/nvim-0.12.6`,
команда `~/.local/bin/nvim`. Плагины закреплены в `nvim-pack-lock.json`.

## Начать работу

Открой терминал в каталоге проекта и запусти `nvim .`.
В файловом менеджере Enter открывает файл, `h` переходит к родительскому каталогу.
Нажми `i` для ввода текста, Esc для выхода из режима ввода, `:w` для сохранения,
`:q` для выхода. Пробел — клавиша Leader; сочетания вводятся последовательно.

| Клавиши | Действие |
|---|---|
| `;f` | Найти файл |
| `;r` | Поиск текста в проекте |
| `sf` | Файловый менеджер Oil |
| `;g` | Lazygit |
| `gd` / `gr` | Определение / места использования |
| `K` | Документация под курсором |
| `Space ca` | Действия над кодом и исправления Ruff |
| `Space cr` | Переименовать символ |
| `Alt + клик` / `Ctrl + клик` | Добавить или убрать курсор в normal mode |
| `Space mn` / `Space ms` | Добавить следующее совпадение / пропустить его |
| `Space mc` | Поставить курсор и приостановить остальные; повторить в другой позиции |
| `Esc` в normal mode с несколькими курсорами | Включить приостановленные курсоры / убрать дополнительные |
| `Space f` | Форматировать |
| `Ctrl+j` | Следующая диагностика |
| `ss` / `sv` | Разделить окно горизонтально / вертикально |
| `sh`, `sj`, `sk`, `sl` | Перейти между окнами |
| `te` / Tab / Shift+Tab | Новая вкладка / следующая / предыдущая |

## Автодополнение

В режиме ввода (`i`) blink.cmp автоматически показывает меню вариантов.
Для Python названия, типы и методы предоставляет basedpyright.

| Клавиши | Действие |
|---|---|
| `Ctrl+Space` | Вызвать меню вручную (поддерживается также передача как Ctrl+@) |
| `Ctrl+n` / `Ctrl+p`, стрелки вниз / вверх | Следующий / предыдущий вариант |
| Enter / `Ctrl+y` | Принять вариант |
| `Ctrl+e` | Отменить выбор и закрыть меню |
| Tab / Shift+Tab | Следующее / предыдущее поле сниппета |

Во время записи макроса blink.cmp отключает автодополнение. Если случайно
включил запись (индикатор `recording @s` или другая буква регистра), нажми
Esc, затем `q`, чтобы остановить её. Самостоятельная `q` в обычном режиме
начинает запись макроса; для закрытия окна используй `:q` или `Ctrl+w`, затем `c`.

Copilot предлагает продолжения прямо в строке: `Ctrl+l` принимает подсказку
целиком, `Alt+l` — одно слово, `Ctrl+]` скрывает подсказку.

## Python

* basedpyright: дополнение, навигация, типы (режим basic).
* Ruff: диагностика, исправления, сортировка импортов и форматирование.
  Сортировка и форматирование выполняются при сохранении.
  `:ToggleFormatter` отключает автоформатирование для текущего буфера.
* Treesitter: синтаксис Python, отступы в четыре пробела.
* nvim-dap, debugpy и dap-ui: точки останова, шаги, переменные и стек.

Интерпретатор выбирается для каждого проекта: вручную выбранный путь,
затем `.venv/bin/python`, `venv/bin/python`, `env/bin/python`, затем активное
`VIRTUAL_ENV`/`CONDA_PREFIX`, затем `python3` из PATH. Один интерпретатор
используется для basedpyright, запуска программы, pytest и отладки.
Если создашь окружение после открытия файла, выполни `:PythonSelect`.
Ручной выбор действует до закрытия Neovim.

| Клавиши | Действие |
|---|---|
| `Space pr` | Сохранить и запустить текущий Python-файл |
| `Space pt` | Сохранить и запустить pytest для текущего файла |
| `Space pT` | Сохранить текущий файл и запустить pytest проекта |
| `Space pv` / `:PythonSelect` | Выбрать интерпретатор |
| `Space pi` / `:PythonInfo` | Показать выбранный интерпретатор |
| F5 / `Space bc` | Начать / продолжить отладку |
| F10 / `Space bo` | Шаг с обходом |
| F11 / `Space bi` | Шаг внутрь |
| F12 | Шаг наружу |
| `Space bb` | Добавить / убрать точку останова |
| `Space bu` | Показать / скрыть панели отладки |
| `Space be` | Остановить отладку |
| `Space bn` | Отладить ближайший pytest-тест |

Для терминала запуска: `Ctrl+\`, затем `Ctrl+n` возвращает обычный режим,
после чего `:q` закрывает панель. Пакет pytest и зависимости приложения должны
быть установлены в окружение самого проекта. Инструменты редактора Mason
устанавливает отдельно, в `~/.local/share/nvim/mason`.

Для существующего uv-проекта сначала используй `uv sync`.
Для нового простого проекта можно создать окружение командами:

```sh
uv venv
uv pip install pytest
nvim .
```

## Обслуживание

`:Mason` показывает установленные языковые серверы и инструменты.
`:checkhealth` запускает проверки окружения, `:ConformInfo` показывает форматтеры.
Для осознанного обновления плагинов: `:lua vim.pack.update()`;
проверь предложенные изменения и сохрани буфер обновления через `:w`.
Copilot из оригинального конфига требует отдельной авторизации `:Copilot auth`.
Для иконок в терминале нужен Nerd Font; Hack Nerd Font уже установлен в системе.

Предыдущий `~/dotfiles/nvim` сохранён без изменений. Резервная копия исходной
ссылки, снимок конфига и старые данные плагинов:
`~/.local/state/nvim-backups/20261106-115021/`.
Для отката закрой Neovim и выполни:

```sh
python3 ~/.local/state/nvim-backups/20261106-115021/restore.py
```

Откат сохраняет новую настройку в подкаталог `replaced-*` этой резервной копии.
После отката `nvim` снова использует прежнюю системную версию.

## Markdown Preview

Установлен [markdown-preview.nvim](https://github.com/iamcco/markdown-preview.nvim)
через vim.pack; используется готовый Linux-бинарник. При установке/обновлении
плагина бинарник загружается автоматически.

Открой `.md` и нажми `Space mp` в normal mode для переключения предпросмотра
в браузере. Команды: `:MarkdownPreview`, `:MarkdownPreviewStop`,
`:MarkdownPreviewToggle`. Сервер доступен только локально.

## Сообщение коммита

Добавь нужные изменения в индекс через `;g` → Space на файлах. Затем в обычном
окне файла нажми `Space gm`: Copilot сгенерирует английское сообщение Conventional
Commit и скопирует его в системный буфер обмена. Коммит автоматически не создается.

Утилита передает staged diff непосредственно в запрос. Если diff превышает
100 000 байт, в запрос включаются статистика изменений и сокращенный diff без
содержимого распространенных lock-файлов. В этом случае уведомление предупреждает,
что модель видит не все изменения: проверь полученное сообщение перед коммитом.
Ошибки генерации показываются уведомлением; пустой ответ или текст без заголовка
Conventional Commit не заменяет буфер обмена. Используется модель из настройки
CopilotChat (claude-haiku-4.5).
